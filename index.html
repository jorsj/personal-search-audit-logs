Les comparto los módulos de Terraform, las instrucciones paso a paso y las consultas de BigQuery para exportar los Data Access Audit Logs (DATA_READ) de Personal Search (cuando un usuario realiza una búsqueda o abre un documento) desde el Proyecto 1 (donde vive la app y el stack de búsqueda) hacia una tabla particionada de BigQuery en el Proyecto 2.

3. Estructura de la tabla en BigQuery y Schema de los Payloads

Al usar un sink con use_partitioned_tables = true, Cloud Logging crea automáticamente en el Proyecto 2 la tabla particionada por día:
<PROYECTO_2_BIGQUERY>.<DATASET_ID>.cloudaudit_googleapis_com_data_access

Columnas de nivel superior de la tabla

  • timestamp (TIMESTAMP): Fecha y hora exacta del evento (columna de partición diaria).
  • insertId (STRING): ID único de la entrada de log.
  • logName (STRING): projects/<PROYECTO_1>/logs/cloudaudit.googleapis.com%2Fdata_access.
  • severity (STRING): Severidad (INFO, NOTICE, ERROR).
  • resource (RECORD): resource.type (audited_resource / gcs_bucket) y resource.labels (project_id, service, method).
  • protopayload_auditlog (RECORD): Contiene el payload google.cloud.audit.AuditLog con todo el detalle de la llamada a la API.

Campos clave dentro de protopayload_auditlog

  • protopayload_auditlog.serviceName (STRING): discoveryengine.googleapis.com o storage.googleapis.com.
  • protopayload_auditlog.methodName (STRING): google.cloud.discoveryengine.v1.SearchService.Search o storage.objects.get.
  • protopayload_auditlog.resourceName (STRING):
    • En búsquedas: projects/<PROYECTO_1>/locations/global/collections/default_collection/engines/<ENGINE_ID>/servingConfigs/default_search
    • En apertura de documentos: projects/_/buckets/<BUCKET_NAME>/objects/<RUTA_ARCHIVO.pdf>
  • protopayload_auditlog.authenticationInfo.principalEmail (STRING): Cuenta autenticada que ejecutó la llamada.
  • protopayload_auditlog.requestMetadata.callerIp (STRING): IP del cliente (y callerSuppliedUserAgent).
  • protopayload_auditlog.requestJson (STRING en formato JSON): Parámetros de entrada (SearchRequest).
  • protopayload_auditlog.responseJson (STRING en formato JSON): Respuesta de la API (SearchResponse). En SearchService.Search, el array $.results[*].id trae los IDs de los documentos devueltos como resultados en esa búsqueda.

4. Orden e Instrucciones de Ejecución (Primero Proyecto 1 y después Proyecto 2)

El paquete personal-search-audit-logs-terraform.zip contiene dos carpetas independientes (project-1-sink y project-2-bigquery):

Paso 1 — Ejecutar primero project-1-sink (en el Proyecto 1 donde vive Personal Search)

Cloud Logging permite crear el sink apuntando al dataset del Proyecto 2 aunque ese dataset todavía no exista, y en ese momento aprovisiona la cuenta de servicio única del sink (sink_writer_identity = serviceAccount:service-<PROJECT_1_NUMBER>@gcp-sa-logging.iam.gserviceaccount.com).

bash — Proyecto 1 
cd audit-logs/project-1-sink
cp terraform.tfvars.example terraform.tfvars
# Editar terraform.tfvars con app_project_id (Proyecto 1) y bigquery_project_id (Proyecto 2)
terraform init
terraform apply

# Copiar el writer identity para pasarlo al Proyecto 2:
terraform output -raw sink_writer_identity

Paso 2 — Ejecutar después project-2-bigquery (en el Proyecto 2 donde vive BigQuery)

Crea el dataset en BigQuery y le asigna el rol roles/bigquery.dataEditor al sink_writer_identity obtenido en el Paso 1.

bash — Proyecto 2 
cd audit-logs/project-2-bigquery
cp terraform.tfvars.example terraform.tfvars
# Editar terraform.tfvars con bigquery_project_id (Proyecto 2) y sink_writer_identity
terraform init
terraform apply

5. Consultas SQL en BigQuery (Proyecto 2)

5.1. Ver eventos recientes (SEARCH y DOCUMENT_OPEN)

BigQuery SQL — Eventos recientes 
SELECT
  timestamp,
  CASE
    WHEN protopayload_auditlog.serviceName = 'discoveryengine.googleapis.com' THEN 'SEARCH'
    WHEN protopayload_auditlog.serviceName = 'storage.googleapis.com'         THEN 'DOCUMENT_OPEN'
  END AS user_action,
  protopayload_auditlog.serviceName AS service_name,
  protopayload_auditlog.methodName AS method_name,
  protopayload_auditlog.resourceName AS resource_name,
  protopayload_auditlog.authenticationInfo.principalEmail AS principal_email,
  protopayload_auditlog.requestMetadata.callerIp AS caller_ip
FROM
  `<PROYECTO_2_BIGQUERY>.personal_search_audit_logs.cloudaudit_googleapis_com_data_access`
WHERE
  TIMESTAMP_TRUNC(timestamp, DAY) >= TIMESTAMP_SUB(CURRENT_TIMESTAMP(), INTERVAL 7 DAY)
ORDER BY
  timestamp DESC
LIMIT 100;

5.2. Calcular el CTR por Documento

Al indexar archivos desde Cloud Storage (gs://<bucket>/<objeto>), Discovery Engine genera el doc_id tomando los primeros 32 caracteres hexadecimales de SHA256("gs://<bucket>/<objeto>") (SUBSTR(TO_HEX(SHA256(gcs_uri)), 1, 32)), y en protopayload_auditlog.responseJson guarda los $.results[*].id devueltos en cada búsqueda. Cruzando ese doc_id con las aperturas en storage.objects.get se obtiene el CTR por documento:

BigQuery SQL — CTR por documento 
WITH
  impressions AS (
    SELECT
      JSON_VALUE(result, '$.id') AS doc_id,
      COUNT(*) AS search_impressions
    FROM
      `<PROYECTO_2_BIGQUERY>.personal_search_audit_logs.cloudaudit_googleapis_com_data_access`,
      UNNEST(JSON_QUERY_ARRAY(protopayload_auditlog.responseJson, '$.results')) AS result
    WHERE
      protopayload_auditlog.serviceName = 'discoveryengine.googleapis.com'
      AND protopayload_auditlog.methodName = 'google.cloud.discoveryengine.v1.SearchService.Search'
    GROUP BY
      doc_id
  ),
  clicks AS (
    SELECT
      gcs_uri,
      SUBSTR(TO_HEX(SHA256(gcs_uri)), 1, 32) AS doc_id,
      COUNT(*) AS document_opens
    FROM (
      SELECT
        CONCAT(
          'gs://',
          REGEXP_EXTRACT(protopayload_auditlog.resourceName, r'buckets/([^/]+)/objects/'),
          '/',
          REGEXP_EXTRACT(protopayload_auditlog.resourceName, r'buckets/[^/]+/objects/(.+)$')
        ) AS gcs_uri
      FROM
        `<PROYECTO_2_BIGQUERY>.personal_search_audit_logs.cloudaudit_googleapis_com_data_access`
      WHERE
        protopayload_auditlog.serviceName = 'storage.googleapis.com'
        AND protopayload_auditlog.methodName = 'storage.objects.get'
    )
    GROUP BY
      gcs_uri
  )
SELECT
  COALESCE(c.gcs_uri, CONCAT('doc_id:', i.doc_id)) AS document,
  i.doc_id,
  IFNULL(i.search_impressions, 0) AS impressions,
  IFNULL(c.document_opens, 0) AS opens,
  ROUND(SAFE_DIVIDE(IFNULL(c.document_opens, 0), i.search_impressions) * 100, 2) AS ctr_pct
FROM
  impressions i
FULL OUTER JOIN
  clicks c
USING (doc_id)
ORDER BY
  opens DESC, impressions DESC;

6. Archivos incluidos en personal-search-audit-logs-terraform.zip

Módulo 1: audit-logs/project-1-sink/main.tf

project-1-sink/main.tf 
locals {
  sink_filter = <<-EOT
    log_id("cloudaudit.googleapis.com/data_access")
    AND (
      (
        protoPayload.serviceName="discoveryengine.googleapis.com" AND
        protoPayload.methodName="google.cloud.discoveryengine.v1.SearchService.Search"
      )
      OR (
        protoPayload.serviceName="storage.googleapis.com" AND
        protoPayload.methodName="storage.objects.get"
      )
    )
  EOT

  audit_config_services = toset([
    "discoveryengine.googleapis.com",
    "storage.googleapis.com",
  ])

  required_apis = toset([
    "logging.googleapis.com",
    "cloudresourcemanager.googleapis.com",
    "serviceusage.googleapis.com",
    "discoveryengine.googleapis.com",
    "storage.googleapis.com",
  ])
}

resource "google_project_service" "apis" {
  for_each = local.required_apis

  project            = var.app_project_id
  service            = each.value
  disable_on_destroy = false
}

resource "google_project_iam_audit_config" "user_actions" {
  for_each = local.audit_config_services

  project = var.app_project_id
  service = each.value

  audit_log_config {
    log_type = "DATA_READ"
  }

  depends_on = [
    google_project_service.apis,
  ]
}

resource "google_logging_project_sink" "audit_logs" {
  project     = var.app_project_id
  name        = var.sink_name
  description = "Exporta los Data Access Audit Logs de búsqueda (Discovery Engine) y apertura de documentos (GCS) hacia BigQuery en ${var.bigquery_project_id}:${var.bigquery_dataset_id}."

  destination = "bigquery.googleapis.com/projects/${var.bigquery_project_id}/datasets/${var.bigquery_dataset_id}"
  filter      = local.sink_filter

  unique_writer_identity = true

  bigquery_options {
    use_partitioned_tables = true
  }

  depends_on = [
    google_project_service.apis,
  ]
}

Módulo 2: audit-logs/project-2-bigquery/main.tf

project-2-bigquery/main.tf 
locals {
  resolved_sink_writer_identity = (
    var.sink_writer_identity != null
    ? var.sink_writer_identity
    : "serviceAccount:service-${var.app_project_number}@gcp-sa-logging.iam.gserviceaccount.com"
  )

  required_apis = toset([
    "bigquery.googleapis.com",
    "bigquerystorage.googleapis.com",
    "cloudresourcemanager.googleapis.com",
    "logging.googleapis.com",
    "serviceusage.googleapis.com",
  ])
}

resource "google_project_service" "apis" {
  for_each = local.required_apis

  project            = var.bigquery_project_id
  service            = each.value
  disable_on_destroy = false
}

resource "google_bigquery_dataset" "audit_logs" {
  project       = var.bigquery_project_id
  dataset_id    = var.bigquery_dataset_id
  friendly_name = "Personal Search Audit Logs"
  description   = "Audit logs (DATA_READ) de búsquedas (Discovery Engine) y apertura de documentos (GCS) de Personal Search."
  location      = var.bigquery_location

  labels = {
    managed_by = "terraform"
    purpose    = "personal-search-audit-logs"
  }

  depends_on = [
    google_project_service.apis,
  ]
}

resource "google_bigquery_dataset_iam_member" "sink_writer" {
  project    = var.bigquery_project_id
  dataset_id = google_bigquery_dataset.audit_logs.dataset_id
  role       = "roles/bigquery.dataEditor"
  member     = local.resolved_sink_writer_identity
}
